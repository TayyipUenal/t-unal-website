# Claude project instructions

Read AGENTS.md and follow its project workflow. The owner authorizes committing and pushing the changes of each successfully completed coding task without another confirmation.

Run Git commands from the repository root, using explicit file paths when staging. The repository is weysi/t-unal, and main tracks origin/main. Use git push origin main when working on main; use the configured upstream on other branches.

Local command permissions are configured in .claude/settings.local.json. An existing session's permission mode or managed policy can override these settings. If Bash is unavailable, report that limitation rather than claiming Git commands were executed.
