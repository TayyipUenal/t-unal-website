## Fixes found on the way

- **Reduced motion hid content (also on the live site).** Reveal primitives rendered their hidden state on the server and skipped the reveal for reduced-motion visitors, so headings, kickers and the whole configurator card stayed invisible. They now start hidden like the server render and reveal immediately; `MotionConfig reducedMotion="user"` makes the remaining transforms instant.
- **framer-motion scroll acceleration.** Array-style `useTransform` chains of a targeted `useScroll` are handed to a native ViewTimeline animation that produced wrong values here. All scroll-linked styles read from a JavaScript copy (`useScrollCopy` in `src/hooks.ts`).
- **Logo over dark sections.** The logo drops its white background with a multiply blend, which fails on a translucent glass header; the scrolled header is solid white.
- **No-JS safety net.** A `<noscript>` style reveals elements that the scroll animations would otherwise keep hidden.

```sh
FTP_USER=w0212c46 sh scripts/deploy-2026-09-17.sh

```

The deploy script picks up the new hashed bundles automatically and keeps the old ones on the server. `api/inquiry.php` changed in revision 3 (two new topics); the script uploads it with the other PHP files. For rollback, the live revision-3 HTML pages are saved in `deployment-backups/2026-09-23-before/`; re-uploading them restores the previous version because its bundles stay on the server.
